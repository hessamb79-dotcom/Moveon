# سایت Move On (مووآن)

One frame ahead...

## ساختار پوشه‌ها

| مسیر | چه چیزی داخلش است |
|---|---|
| `index.html` | صفحه‌ی اصلی سایت |
| `css/style.css` | ظاهر سایت (رنگ، فونت، چیدمان) |
| `js/main.js` | رفتار سایت (پخش ویدیو، گالری، شمارنده) |
| `js/data.js` | **تنها فایلی که برای اضافه کردن نمونه‌کار لازم است ویرایش کنید** |
| `assets/videos` | فایل ویدیوها (mp4) |
| `assets/posters` | عکس کاور هر ویدیو (jpg) |
| `assets/works` | عکس نمونه‌کارهای گرافیک (webp یا jpg) |
| `assets/logos` | لوگوی برندهای همکار (png یا svg) |
| `assets/fonts` | فونت‌ها |

## اضافه کردن ویدیوی آپارات

در `js/data.js` داخل بخش `aparat` یک خط اضافه کنید. فقط کد آخر لینک را بنویسید:

```js
{ id: "abc1234", title: "عنوان ویدیو" },
```

## اضافه کردن ویدیوی جدید داخل سایت

۱. حجم ویدیو را کم کنید (پایین‌تر توضیح داده شده). هر فایل باید زیر ۲۵ مگابایت باشد؛ بهتر است زیر ۵ مگابایت.
۲. اسم فایل را انگلیسی، بدون فاصله و با خط تیره بگذارید؛ مثلاً `new-project.mp4`.
۳. فایل را در `assets/videos` آپلود کنید.
۴. یک عکس کاور با همان اسم (`new-project.jpg`) در `assets/posters` بگذارید.
۵. در `js/data.js` داخل بخش `videos` یک خط اضافه کنید:

```js
{ file: "new-project.mp4", poster: "new-project.jpg", title: "عنوان", tag: "موشن گرافیک", shape: "tall" },
```

برای ویدیوی افقی به‌جای `tall` بنویسید `wide`.

## اضافه کردن عکس نمونه‌کار

۱. عرض یا ارتفاع عکس را حداکثر ۱۴۰۰ پیکسل کنید و با کیفیت ۸۰٪ ذخیره کنید (webp یا jpg).
۲. اسم فایل را انگلیسی و بدون فاصله بگذارید؛ مثلاً `new-poster.webp`.
۳. در `assets/works` آپلود کنید.
۴. در `js/data.js` داخل بخش `works` یک خط اضافه کنید:

```js
{ src: "new-poster.webp", thumb: "new-poster.webp", cat: "poster", title: "عنوان نمونه‌کار" },
```

دسته‌ها (`cat`): `social` شبکه‌های اجتماعی، `poster` پوستر و رویداد، `event` نمایشگاه، `thumb` تامبنیل، `identity` هویت بصری.

## اضافه کردن لوگوی برندها

لوگو را با همان اسمی که در بخش `clients` فایل `js/data.js` نوشته شده (مثلاً `iranserver.png`) در `assets/logos` بگذارید. لوگو خودکار جای اسم برند می‌نشیند. بهترین حالت: PNG با پس‌زمینه‌ی شفاف یا SVG.

## فونت

کل سایت، فارسی و انگلیسی، با فونت مربع (Morabba) است و فایل‌هایش در `assets/fonts` قرار دارد.

## فعال کردن دکمه‌های بله و ایتا

در `index.html` لینک‌های `https://ble.ir/` و `https://eitaa.com/` را با آیدی خودتان کامل کنید (مثلاً `https://ble.ir/moveon`) و عبارت `data-todo="bale"` و `data-todo="eitaa"` را پاک کنید.

## کم کردن حجم ویدیو

ساده‌ترین راه برنامه‌ی رایگان **HandBrake** است: ویدیو را باز کنید، از Preset گزینه‌ی **Fast 720p30** را انتخاب کنید، در تب Video مقدار **RF را روی ۲۸** بگذارید، تیک **Web Optimized** را بزنید و خروجی بگیرید.
